# Graphen-Werkstatt – Verschieben und Strecken von Funktionsgraphen

Interaktives Lerntool für Mathematik Klasse 11 (Bayern), ca. 8 Minuten:

1. **Entdecken** – Regler a, b, c, d für g(x) = a · f(b · (x + c)) + d
2. **Zielgraph treffen** – 6 Missionen
3. **Quiz** – 6 Fragen
4. **Ergebnis** – Merkregeln und Exit-Ticket

Die Seite besteht aus einer einzigen Datei (`index.html`) und läuft über GitHub Pages.
